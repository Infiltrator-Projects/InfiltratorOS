# MB Corpo fonts

InfiltratorOS owns the repository copies of the three MB Corpo faces used by the native Infiltrator desktop on Linux. These files are intentionally committed to this repository so an InfiltratorOS package can establish `/System/Resources/Fonts` without downloading font payloads during installation.

Files and required SHA-256 values:

- `mb_corpo_a_cond_regular.ttf` — `c8bcd7e1a7d71169b38491d9b7c1ffe7ba7b46e888f0c1219931343a47bc0e05`
- `mb_corpo_s_bold.ttf` — `d37ea986e2344d83390f94f170e6272b56efd00bfec808afe8314c4ca45d43b4`
- `mb_corpo_s_regular.ttf` — `94ede6629443c03d4362dcef425fb3ff520be5d654370021a34e81286804465c`

The initial repository copies were imported from the previously qualified MBLink source at commit `aa161e7342112beab8feb7669f072c870f742765`. The hashes above remain the executable identity of the current font resources.
